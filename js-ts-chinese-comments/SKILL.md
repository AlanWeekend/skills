# JS / TS 中文接口契约注释

产出紧邻声明的 `/** ... */` 接口说明，帮助调用者理解函数如何使用、类型表示什么。在 Vue 脚本中适用于普通业务函数与通用类型。

## 覆盖内容

| 对象 | 说明内容 |
| --- | --- |
| 函数、方法、构造器 | 用途，参数含义、默认行为、结果、异常及调用方可观察的副作用 |
| 箭头函数与回调 | 调用目的及重要输入输出；短回调可由紧邻的整体调用说明覆盖 |
| 类、接口、类型别名、枚举 | 业务语义、约束和使用边界 |
| 成员与复杂泛型 | 字段含义、可选与空值语义、联合类型差异、类型参数及约束 |

每个涉及的自定义函数和类型都应有准确说明；简单接口可用一句中文完整表达。

## 写法与维护

- JSDoc 标签如 `@param`、`@returns`、`@throws`、`@template` 保持英文，解释使用简体中文；重点补充类型声明无法表达的业务含义。
- 返回值说明实际结果和异步完成含义；异常与副作用依据实现及调用契约确认。
- 声明或整体调用处已有完整说明时直接维护，同一契约只写一次。
- 保持注释位置合法，尤其是 JSX 属性表达式；保留工具指令与目标语句的绑定关系。
- 只补注释时保持代码结构、签名、类型与行为不变；处理目标范围内的自有源码。

接口和回调示例见 [references/examples.md](references/examples.md)。

## 检查

对照实现核对参数、结果、异常、空值和副作用；按改动风险运行项目现有解析、格式或类型检查。
