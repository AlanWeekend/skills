# Python 中文文档字符串

产出能被 Python 和文档工具识别的中文 Docstring，便于阅读源码、查看类和悬停函数。

## 覆盖与位置

- 每个涉及的自有模块有用途说明，复用已有的模块 Docstring；位于 shebang / 编码声明之后、import 及 future import 之前。
- 每个类说明职责、依赖与重要属性；构造参数在类或构造器的一处完整说明。
- 每个自定义函数、方法、async 函数及业务私有辅助函数有说明；短函数可用准确的一句。
- 类和函数的 Docstring 是各自正文的第一条语句。property 说明值语义、可空性及读取副作用；生成器说明每次产出的内容。
- 数据类、TypedDict 和模型字段按合法形式补充中文语义。

## 文档内容

沿用项目已有风格，新项目默认 Google 风格。首句写用途，按真实接口选择章节：

| 标签 | 内容 |
| --- | --- |
| `Args:` | 参数业务含义、单位、默认行为与约束 |
| `Returns:` | 返回结果、空值和状态语义；仅返回 None 时按实际需要说明 |
| `Yields:` | 每次产出的内容及停止条件，适用于同步或异步生成器 |
| `Raises:` | 调用者需要处理的实际异常及触发条件 |
| `Attributes:` | 重要属性及其业务语义 |
| `Examples:` | 非直观接口的可验证用法 |

标签与标识符保持英文，解释使用简体中文。补充调用方可观察的副作用、资源归属、异步完成和幂等约定，内容以实际实现为准。

## 维护与检查

- 已有准确说明直接维护，同一份模块用途或调用约定只写一次。
- 只补注释时保持代码结构、签名、类型、装饰器和行为不变；处理目标范围内的自有源码。
- 使用现有解析、lint 或针对性检查确认文档合法；有 doctest 或可运行示例时按需验证。框架对外展示 Docstring 时核对生成文档。

模块、类、函数及生成器示例见 [references/examples.md](references/examples.md)。
