# 中文逻辑与流程注释

面向需要审查实现细节的中文读者，产出贴近函数体和业务逻辑的注释。

## 注释内容

- 每个涉及的函数说明主要处理步骤；短实现可由已有的紧邻函数说明完整覆盖。
- 业务分支、循环、异常处理、转换和异步等待说明触发条件、处理对象及目的。
- 重要变量、状态与配置说明业务含义、单位、取值范围或状态转换。
- 难理解的解构、闭包、生成器、装饰器、泛型或上下文管理语法，解释其在当前实现中的实际作用。
- 外部读写、权限检查、事务、并发、取消、重试与资源释放，说明已实现的边界和失败处理。

## 写法与维护

- 先核对实现和必要的调用上下文；业务含义不明时查证或标明待确认。
- 说明使用简体中文，标识符和必要术语保留英文。用具体业务表达代替逐行翻译代码。
- 注释放在对应逻辑块之前；相邻语句共享意图时共用一段说明，已有准确内容直接维护。
- 只补注释时保持代码结构、接口和行为不变，保留许可证及工具指令；处理目标范围内的自有源码。

需要校准详细程度时，阅读 [references/examples.md](references/examples.md)。

## 检查

核对主要步骤、关键分支和副作用是否解释清楚，说明是否与实现一致；按改动风险运行现有解析、格式或针对性检查。
