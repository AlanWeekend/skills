# 数据库表与字段中文注释

用简体中文说明表和字段的真实业务语义，标识符沿用项目约定。先确认数据库版本、schema、ORM 与迁移方式。

## 说明内容

新建表及其字段都应有中文说明；存量变更维护涉及的表和字段。

- 表：保存的业务对象、用途或记录粒度，必要时说明生命周期和与相似表的区别。
- 字段：先写业务含义，再按实际需要补充以下语义。

| 类别 | 说明重点 |
| --- | --- |
| 标识与关联 | 记录或稳定对象的身份、引用对象、本地或外部来源 |
| 状态与枚举 | 实际允许的值及含义，较长字典的契约位置 |
| 金额与度量 | 币种、单位、精度或数量含义 |
| 时间 | 对应事件、日期或时间点、时区基准与精度 |
| 可空与默认 | NULL、空字符串、零和默认值的业务区别 |
| JSON 等结构化值 | 保存内容及结构契约或版本的维护位置 |
| 冗余、快照与派生值 | 来源、计算或快照时点及实际更新方式 |

说明以实现和已确认约定为依据，未知含义列为待确认项。

## 注释载体与迁移

- 数据库支持表列元数据注释时，维护实际 schema comment；核对 ORM 配置和迁移能将说明写入数据库。接口描述字段与数据库注释分别确认。
- 已发布或应用的迁移通过追加变更维护。仅修改注释时保留原结构；方言要求重述列定义时，先取得完整真实定义。
- SQL 文本正确转义，schema、表与列名使用项目受控元数据。面向外部文档时采用可公开的业务表述。
- 引擎缺少对应元数据能力时，使用邻近 SQL 注释和项目已有数据字典，并说明限制。

按任务选择参考：[SQL 方言](references/sql-dialects.md)、[SQLModel 与 Alembic](references/sqlmodel-alembic.md)、[SQLAlchemy 与 Alembic](references/sqlalchemy-alembic.md)。

## 检查

核对模型、DDL、迁移和元数据中的说明及变更范围。具备已授权的兼容测试库时，验证初始化或存量升级、必要的回退及元数据结果；交付时区分静态检查与实际执行结果。
