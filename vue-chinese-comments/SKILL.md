# Vue 页面与组件中文注释

说明组件对外约定、响应式数据如何流动，以及业务状态如何展示。

## 覆盖内容

| 对象 | 说明内容 |
| --- | --- |
| Props / Emits / Slots / v-model | 输入用途、默认与空值语义、事件时机和载荷、插槽职责及同步约定 |
| ref / reactive / computed | 状态的业务含义、来源和派生依据 |
| watch / watchEffect | 监听来源、触发时机、首次执行行为及副作用 |
| 生命周期、订阅与清理 | 注册来源、组件生命周期边界、停止条件及实际清理位置 |
| 模板业务区域 | 筛选、表单、列表、详情、弹窗和状态反馈的目的，复杂条件链、循环与插槽的业务语义 |
| 非直观样式 | 布局约束、第三方样式覆盖原因或兼容处理 |

## 写法与维护

- 使用简体中文，按组件实际实现说明机制；已有说明同时涵盖类型语义时维护同一处。
- 模板使用 HTML 注释，放在完整业务区块或条件链之前，保持 `v-if` / `v-else-if` / `v-else` 的相邻关系。
- 插槽、Transition 等依赖直接子节点的结构，将说明放在合适的外层或脚本处；属性值和插值表达式保持原样。
- 只补注释时保持代码结构和运行行为不变；处理目标范围内的自有组件。

专项示例见 [references/examples.md](references/examples.md)。

## 检查

核对组件契约、响应式状态、生命周期与模板说明的一致性；运行项目已有 Vue 解析、格式或类型检查，涉及关键 UI 时按需核对渲染。
