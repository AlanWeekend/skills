# 中文文件用途说明

在文件开头说明它负责什么、如何被使用；已有准确说明时维护同一处。

## 说明内容

- 第一段写具体用途，区分页面、可复用组件、业务服务、基础设施和入口。
- 按实际复杂度补充主要职责、调用入口、关键依赖、输入输出和重要边界；简单文件一句话即可。
- 页面与组件说明服务的交互及数据来源；服务说明处理的用例和调用方。内容以代码及项目约定为依据。

## 合法位置

| 文件类型 | 方式与位置 |
| --- | --- |
| Vue SFC | 默认在文件开头使用顶层 `<!-- ... -->`；已有统一 script 文件头时维护原说明 |
| JS / TS / JSX / TSX | 使用 `/** ... */` 模块说明，保留 shebang、许可证、三斜线引用及必须置顶的指令 |
| Python | 使用模块 Docstring，位于 shebang / 编码声明之后、import 及 `from __future__` 之前，成为模块第一条语句 |
| 其他语言 | 使用语言合法的文件或模块文档注释，遵循编译器的位置要求 |
| JSON 等无注释语法的格式 | 通过相邻维护文档说明用途 |

保留许可证和来源声明。Python 模块用途复用同一份 Docstring；有实际包职责的 `__init__.py` 使用简短包说明。生成文件及第三方源码沿用其维护流程。

不同语言的位置示例见 [references/examples.md](references/examples.md)。

## 检查

确认用途具体、准确且只说明一次。只补注释时保持代码结构与行为不变，并用现有解析或格式检查确认注释合法。
